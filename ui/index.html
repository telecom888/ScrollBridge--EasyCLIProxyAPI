域名与隧道
  1. 1
    将域名接入 Cloudflare DNS
    保留注册商，按 Cloudflare 提示更新域名服务器。
  2. 2
    创建命名隧道
    在 Networking → Tunnels 创建隧道，将连接令牌填入「连接配置」。
  3. 3
    添加公开应用路由
    主机名填写你的 API 子域名，服务地址填写下方地址。
    http://127.0.0.1:18443
  4. 4
    启动连接并检测 HTTPS
    DNS 和证书生效后，在「接入」页检查域名。

      
创建命名隧道和 CNAME，绑定「连接配置」中已保存的域名。已有 DNS 记录不会被覆盖。API 令牌仅用于本次操作。
令牌权限：账户 Cloudflare Tunnel 编辑；区域 DNS 编辑、区域读取。区域 ID 与账户 ID 可在域名概览页找到。
