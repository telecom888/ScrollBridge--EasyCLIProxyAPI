# 0.3.30

## 托管与模型路由

- 新增托管账号、上游密钥及模型管理，支持 OpenAI、Anthropic、Google 和 Vertex AI。托管文本请求可转换协议；不支持的接口会明确报错，详情见托管文档。
- 支持同名模型统一对外 ID、调整来源优先级，以及在明确 HTTP 失败且尚未输出响应时切换来源。网络错误无法确定请求是否执行时，不重发生成请求。
- 按参考图调整托管管理界面。宽窗口分为账号、密钥编辑、模型管理三栏，较窄窗口自动换行；路由优先级使用独立标签。
- 显示来源及统一路由的设置移到「更新」下方的「模型路由」。

## 记录图表

- 新增调用次数图表，可按六个时间范围查看。本机聚合统计加密保存，保留最近 31 天。
- 图表区域隐藏不适用的导出、分页操作，后台更新合并刷新，内容未变化时保留现有图表。

## 修复与配置

- 修复密钥校验正则转义错误，避免合法密钥包含字母 r、n 时被拒绝。
- 修复跨协议 Gemini 流式转换丢失连续相同文字，以及上游错误或未完成响应被错误标记为完成的问题。
- 配置升级至 v4，自动保留 v3 的原有密钥、连接参数和权限。首次保存后旧版本不能直接读取 v4，回退前请保留旧配置备份。
