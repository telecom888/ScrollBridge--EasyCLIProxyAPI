# 0.3.8

Go 网关成为默认主线。桌面 UI、Windows 加密配置及隧道管理继续复用。默认发行文件为 `ScrollBridge-0.3.8-win-x64.exe`，不标注技术栈或 beta。Node 网关源码及历史回归保留，单独构建文件带 `-node`，默认不再双版本打包。

## 密钥与日志

- 请求记录可按全部、单个或多个密钥筛选，使用稳定的内部 ID；重名不会混淆，删除密钥后仍可查询当前内存中的记录。未鉴权请求只出现在全部记录中。
- 每个密钥可独立启用并发限制；关闭时不限制。HTTP 请求和 WebSocket 中每个进行中的生成共享并发名额，WS 空闲连接不占生成名额。
- 每个密钥可独立启用固定周期请求数限制，填写周期数值并选择分钟或小时。窗口从首个有效模型请求开始，窗口结束后下次请求重新计数。
- 未鉴权、无模型权限、正文无效或并发/周期限流拒绝不消耗次数；有效请求被受理后，上游失败也计数。健康检测、模型列表与模型详情查询不计数；公网检测中的实际模型生成请求会计数。超限 HTTP 返回 429，周期超限附 Retry-After；WS 返回带 429 状态的 error 事件。
- 计数为当前网关进程内的运行状态；热更新不会清零。停止再启动连接会重置周期计数。这是单机访问控制，不是跨实例或重启后持续的计费账本。
- UI 和本机管理 API 共用配置与执行逻辑。已有配置新增字段默认关闭，保持原密钥、加密凭据及连接设置。

## 压测问题的代码调整

| 问题 | 调整 |
|---|---|
| 默认活动请求 64，配置最多 4096 | 默认不限制；仍可在独立网关配置中显式限制全局并发，单密钥可单独限制 |
| TCP 接入按并发派生上限，超限直接关连接 | 模型服务监听移除该门禁；管理指标端口的独立小连接保护不变 |
| 上游活动连接固定上限 4096 | 移除活动连接硬上限，继续复用空闲连接 |
| 等待模型时固定 30 秒上游响应头超时 | 请求上下文控制总时长；桌面最长 30 分钟 |
| 客户端写超时从入站时开始，等待上游就耗尽 | 实际开始写出响应时才设置写入期限，每次写入刷新，保留慢读保护 |
| 小请求仍分配并保留 32 KiB 分块，随后再次拼接 | 使用可增长正文缓冲及 4 KiB 读取工作区，避免保留每个大分块 |
| SSE 每连接按最大事件上限预留约 2 MiB | 每流 32 KiB 起步，按观察到的事件/扫描缓冲高水位扩容，结束或出错退还预算 |
| 每个上游 SSE 事件逐 token 严格构建 JSON | 上游事件使用标准 JSON 解码器；客户端请求继续严格拒绝重复字段 |
| 每条请求结束立即向窗口推送完整快照 | 请求日志推送合并到每 100 ms 一次，内存记录仍逐条更新 |

未取消正文大小、事件大小、总输出大小、共享缓冲预算、请求总时长和慢客户端保护；取消固定并发上限并不代表资源无限，也不构成并发容量承诺。
