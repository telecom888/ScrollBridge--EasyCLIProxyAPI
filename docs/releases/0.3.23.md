# 0.3.23

## 请求体查看

- 设置 → 连接新增“显示请求体”开关，默认关闭；关闭仅隐藏查看功能，新请求仍采集有限的正文预览。
- 记录 → 请求新增“请求体”列和“查看”按钮，以纯文本弹窗展示正文，JSON 可格式化阅读。HTML、脚本和 URL 不执行或自动打开。
- 支持查看未通过鉴权和被黑名单拒绝的 HTTP 请求，便于分析扫描载荷；没有正文、二进制上传、未完整收到和无法解码的内容会分别提示。
- 每条预览最多 16 KiB，正文预览总计最多 8 MiB，达到上限时淘汰较早预览并保留请求摘要。受限解压及短时采集超时避免异常上传无限占用连接。
- 正文只保存在本次运行的内存中，随清空、记录淘汰或退出程序删除，不写入配置和计费审计，也不包含在常规 CSV/JSON 导出中。
- 正文按需读取，不随日志快照反复传输；查看时隐藏与本机已配置凭据完全匹配的字符串。提示词及其他业务内容可能仍包含敏感信息。
- 本机管理 API 新增 `GET /api/v1/logs/{id}/body`，需要本机管理令牌且已开启“显示请求体”。

## 修复

- 修复桌面回归脚本在窗口重启后过早读取页面状态的问题。
- 保留 0.3.22 的 IP 显示修复：隐藏 IP 列不影响继续记录新请求的 IP。

本版本上线前未采集的正文无法补回。仅采集有限 HTTP 请求体预览，不提供 WebSocket 消息正文采集。
