# 0.3.22

## 请求 IP

- 将设置中的“记录请求IP”改为“显示请求IP”，开关仅控制请求列表的 IP 列。
- 关闭显示后仍采集新请求的 IP，重新开启后可查看本次运行中尚未被淘汰记录的地址，包括鉴权失败和黑名单拒绝的请求。
- HTTP 和 WebSocket 使用一致的 IP 记录方式，切换显示无需重新配置网关，不中断活动连接。
- 关闭显示时，桌面日志消息及导出文件仍不包含 IP；黑名单继续生效。
- IP 只随有数量上限的请求记录保存在内存中，清空记录或退出程序后删除。更新前未采集的 IP 无法补回。

## 验证

- 增加关闭显示期间接收请求、重新开启后恢复 IP 的桌面回归验证。
- 验证 HTTP 鉴权失败、黑名单拦截和 WebSocket 的 IP 记录。
- 不修改现有访问密钥或配置加密方式。
