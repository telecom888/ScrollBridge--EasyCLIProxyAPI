# 0.3.25

## 弹窗与菜单动画

- 弹窗打开时轻微上移、缩放并带有柔和回弹，关闭时收缩退场，遮罩同步过渡。
- 菜单从操作按钮位置展开，弹窗内容高度变化时平滑调整。
- 支持动画中途关闭和重新打开，保留键盘操作、焦点恢复和模态遮罩行为。
- IP 屏蔽及减少记录数量的确认框改用应用内弹窗，保持视觉一致。
- 未新增动态效果设置。系统文件选择框和启动错误提示仍使用原生窗口。

## 验证

- 新增 Electron 弹窗动画检查，覆盖快速重开、焦点、Esc 取消、内容高度及菜单关闭。
- 更新记录页检查，验证动画弹窗下的黑名单、保留数量和导出操作。
- 在线构建提供免安装 ZIP、安装程序及单 EXE 三种发布包。
