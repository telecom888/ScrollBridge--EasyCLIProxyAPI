# 0.3.15

- 修复更新检测时的 `Redirect was cancelled`：Electron 的 `net.fetch` 无法按此处所需的方式手动处理重定向，已改用 `net.request`，由更新器逐次检查 GitHub 下载地址。
- 保留系统代理、下载流式传输、超时取消、文件大小和 SHA-256 校验。
- 保留「当前版本 → 检测到的版本」显示及三种包的自动安装、重启和配置保留。
- 修复首次 GitHub Actions 发布时的隐式重复发布及输出目录缺失问题。

0.3.13 / 0.3.14 的更新检测受上述重定向问题影响，需要手动替换一次程序。保留 exe 同目录的 `scrollbridge.json`；之后可继续从设置中检测和安装新版本。

测试包含真实 GitHub 清单读取和安装包下载校验，以及三种包的安装、重启和配置保留验证。
