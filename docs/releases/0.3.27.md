# 0.3.27

## 隧道安全更新

- 内置 cloudflared 从 2026.10.1 升级至 2026.10.3，应用 Cloudflare 针对 eMudhra（emSign）证书私钥泄露事件的安全修复。
- 构建时从 Cloudflare 官方 GitHub 下载固定版本，并核对官方公布的 SHA-256。三种发行包均包含更新后的隧道程序。
- 配置文件、客户端密钥和域名配置保持不变。更新后需重启程序和隧道，已运行的旧隧道进程不会因下载新版本而自动获得修复；重启期间公网请求可能中断。
- 若另行部署了 Windows 服务、容器或其他主机上的 cloudflared，需要分别升级。
- 使用 HTTPS 回源且源站证书受此事件影响时，应更换源站证书，不能通过关闭证书验证绕过错误。

参考：[Cloudflare 安全公告](https://blog.cloudflare.com/emudhra-certificate-compromise/)、[cloudflared 2026.10.3](https://github.com/cloudflare/cloudflared/releases/tag/2026.10.3)。
