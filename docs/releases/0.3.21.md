# 0.3.21

## 请求记录

- 设置 → 连接新增“记录请求 IP”开关，默认关闭；启用后显示请求 IP，支持 IPv4、IPv6 和 Cloudflare Tunnel 的访客地址。
- 新增 IP 黑名单，支持设置中管理、请求 IP 菜单中添加和复制；命中后返回 403，不转发到模型服务。关闭 IP 记录不影响黑名单拦截。
- 请求记录可保留 100–10,000 条，默认 200 条；支持每页 100 条浏览，超过上限淘汰最旧记录。
- 支持按当前密钥筛选结果或全部记录导出 CSV、JSON，包含所有分页；关闭 IP 记录时导出不包含 IP。
- 记录只在本次运行内保留，重启后清空；开关、黑名单和保留数量保存到本地配置。
- 使用有上限的内存缓冲和增量刷新，避免每次新增记录都向桌面传输全部历史。

## 更新来源

- 移除 GitCode 更新渠道和自动发布流程，默认改为 GitHub 镜像（gh-proxy）。
- 已选择 GitCode 的配置自动切换到镜像，原先选择 GitHub 的配置保持不变。
- 不更改访问密钥和现有配置加密方式。

请求 IP 用于排查和地址拦截，不替代密钥鉴权。通过本机 cloudflared 转发时使用 Cloudflare 报告的访客地址，本机直连使用连接地址；不会直接采用任意 X-Forwarded-For 中的首个值。

网关仅监听回环地址，并信任本机转发的 Cloudflare 请求头。拥有本机访问权限的进程仍可伪造这类请求头，因此 IP 不作为独立身份凭证。
