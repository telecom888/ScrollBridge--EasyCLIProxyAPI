# 0.3.20

## 更新下载

- 新增 GitCode 下载渠道，新配置默认使用 GitCode；已有配置保留原选择。
- 保留 GitHub 和 GitHub 镜像，支持手动切换来源。
- GitCode 仅发布安装版、免安装 ZIP、单 exe 和校验文件，不同步项目源码。
- 三个渠道均验证同一签名清单和安装包 SHA-256。

## 语音接口

- 设置 → 接口第三项新增“语音接口”，默认关闭。
- 支持 `/v1/audio/speech`，按真实模型 ID 的关键词选择协议；模型别名、全局和单密钥访问规则继续生效。
- 支持标准音频透传和多种原生音频响应转换，含 PCM/WAV、Base64、十六进制与 SSE 音频。
- 上游必须提供对应接口；格式不支持、上游缺失接口或返回无效音频时显示明确错误。
- 已通过本地模拟接口测试，真实厂商服务兼容性取决于本地代理和具体模型。

配置文件、访问密钥及现有加密方式保持不变。
