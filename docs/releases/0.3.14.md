# 0.3.14

- 设置中的更新区域显示「当前版本 → 检测到的版本」，例如 `0.3.13 → 0.3.14`。版本相同时也显示对照；尚未检测或仓库未提供版本时只显示当前版本。
- 提供 ZIP 文件夹版、当前用户安装版和单 EXE 版。检测到更新后，按当前程序形式下载对应安装包，校验后自动升级并重启，保留原配置和访问密钥。
- 本次正式发布包含三种包、SHA-256 校验文件和更新清单。只推送源码不会产生可检测的桌面更新。
- 源码和本次打包使用 GNU GPLv3；第三方组件保留各自许可证。

0.3.13 用户可在「设置 → 外观」下方点击「检测更新」。更早且未包含更新功能的版本需要先手动安装本次发布。网络须能够访问 GitHub Release 下载地址，匿名 API 请求受限时会自动改用 Release 清单检测。

验证覆盖版本比较、无更新、匿名请求限额备用路径、下载完整性、三种包的更新与重启、配置保留以及失败回退；不重新执行高并发压力测试。
