# 请求记录

「记录 → 请求」只保留本次运行的数据，可按全部、单个或多个密钥查询。全部包含没有通过鉴权、无法归属密钥的请求。

## 保留数量与导出

默认保留 200 条，可选择或自定义 100–10,000 条；超过上限淘汰最旧记录，每页显示 100 条。减少数量时若需丢弃已有记录，会先提示确认。隧道消息独立保留最近 100 条。

支持按当前筛选结果或全部已保留记录导出 CSV、JSON，包含所有分页。普通导出不包含请求正文、请求头或 URL 查询参数；关闭 IP 显示时也不导出 IP。CSV 对可能被电子表格当作公式的内容作文本处理。

记录不写入配置文件，清空或退出程序后删除。开关、黑名单和保留数量会保存到配置。

## 请求 IP 与黑名单

「设置 → 连接 → 显示请求IP」只控制 IP 列是否显示，关闭后仍采集新请求的 IP。重新开启后，可显示本次运行中仍保留的地址；更新前未采集的 IP 无法补回。

通过本机 cloudflared 转发时，使用 Cloudflare 的 `CF-Connecting-IP`，支持 IPv4、IPv6 及 Pseudo IPv4 下的原始 IPv6。其他情况使用套接字对端地址，不直接采用任意 `X-Forwarded-For` 中的首个值。

网关只监听回环地址，并信任本机转发的 Cloudflare 请求头。拥有本机访问能力的程序仍可伪造这类请求头，因此 IP 不作为独立身份凭证，不能代替访问密钥。

点击或右键请求 IP，可复制地址、加入黑名单；也可在设置中管理。黑名单支持单个 IPv4/IPv6 地址，命中后返回 403，不转发至本地模型服务。隐藏 IP 列不影响拦截。

## 请求体预览

「显示请求体」默认关闭，仅控制查看入口。HTTP 请求仍采集有限正文预览，包括未鉴权和被黑名单拒绝的请求；开启后在请求行点击「查看」。GET 通常没有正文；此功能不记录 URL 查询参数，也不采集 WebSocket 消息正文。

- 每条最多 16 KiB，所有正文预览合计最多 8 MiB。达到上限时淘汰较早预览，请求摘要仍可保留。
- 正文按需读取，不随日志快照反复发送。JSON 可格式化；HTML、脚本和链接只按纯文本展示，不执行或自动打开。
- 二进制和文件上传不提供文本内容；无法解码、未完整收到、截断或已淘汰的预览会提示状态。
- 异常请求的额外采集受短时读取期限限制；压缩预览也受输出大小限制。
- 预览随记录清空、淘汰或退出删除，不写入配置或计费审计，不出现在普通导出中。更新前没有采集的正文无法恢复。

查看时隐藏与本机已配置凭据完全匹配的字符串，但提示词和其他业务内容仍可能包含敏感信息。显示开关不等同于停止采集。

自动化查询可使用本机管理 API 的日志分页和 `GET /api/v1/logs/{id}/body`，后者要求已开启正文显示，详见 [管理 API](management-api.md)。
