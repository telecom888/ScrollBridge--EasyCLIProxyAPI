# 代码清理与桌面性能审查

审查基线：`836d8db4b4487cbbc6b2db3e09469848881536a7`（0.3.18）。本轮未修改加密方式或用户配置，不启动真实 Cloudflare 隧道，不使用真实模型请求。

## 已处理

- 请求记录、隧道日志使用独立 IPC 批量推送，避免每条日志重新生成模型与密钥视图。窗口隐藏时不推送日志；重新显示后通过完整快照恢复最新记录。本机管理 API 仍读取完整内存记录。
- 记录截断直接调整数组长度，避免每次都复制整个历史数组；复用时间格式化器，减少大量记录的格式化开销。
- Go 桥接层按配置对象缓存密钥名称索引，避免每条记录线性查找全部密钥；配置变化后重建索引，测试覆盖密钥重命名。
- 模型同步使用集合判重，模型目录使用可用模型集合和别名索引，减少嵌套遍历。
- 启动探测复用模型获取入口，删除重复探测函数及不可达的公网探测分支；删除仅由旧测试调用的 `modelAllowed`，实际权限裁决仍由 policy 执行。
- 删除一直隐藏且渲染分支不可达的费用表单及事件处理，保留费用配置、管理 API 和 Go 后端，等待完整产品方案。
- Go 发行包排除仅供 Node 网关使用的三个模块及 busboy、streamsearch、ws；Node 构建和相关源码保留。
- Chromium 语言资源只保留 `zh-CN`、`en-US`，产品自有中文界面及系统主题逻辑不变。

## 更新重启窗口修复

更新助手此前使用 `Start-Process -WindowStyle Hidden` 启动桌面程序，且成功回执只判断渲染器是否初始化，没有确认窗口可见。

助手继续隐藏运行，桌面程序改为正常窗口启动；有效更新启动票据完成初始化后显式恢复、显示窗口。只有窗口可见且未最小化时才写入就绪回执。失败回滚启动也使用正常窗口。发布工作流增加该窗口回归。

## 测量

同一台 Windows 机器、相同 Electron/Go/cloudflared 版本，文件夹大小不包含用户配置和缓存：

| 项目 | 基线 | 清理后 |
| --- | ---: | ---: |
| 文件夹总字节数 | 451,360,460 | 401,528,262 |
| Chromium 语言资源字节数 | 50,643,459 | 1,178,651 |
| 语言资源份数 | 55 | 2 |
| app.asar 字节数 | 1,155,991 | 897,449 |

文件夹减少 49,832,198 字节，约 47.5 MiB、11%。这不是压缩下载包大小。主要剩余体积来自 Electron 与 cloudflared，继续大幅缩小需要另行评估运行框架或部署方式。

渲染对照使用 200 个密钥、100 个模型、200 条请求记录，连续同步调用 20 次日志更新，测量 JavaScript 执行时间：

| 所在页面 | 基线 | 优化后 |
| --- | ---: | ---: |
| 连接页 | 409.6 ms | 0.2 ms |
| 记录页 | 450.0 ms | 106.4 ms |

连接页收益来自取消无关页面重绘。这是本机合成数据下的脚本耗时，不包括完整 IPC、浏览器绘制或网络成本，不代表整机 CPU、内存或网关吞吐提升比例。本轮未重新运行高并发压测。

## 验证

- `npm test`：99 项通过。
- `npm run test:go`：Go 回归、核心编译及 12 项桥接/协议一致性测试通过；`go vet ./...` 通过。
- Node、Go 两套真实网关桌面回归通过：包括独立日志事件、隐藏窗口暂停推送、重新显示补齐、密钥名称更新、别名与全局权限。
- 密钥布局、模型刷新、设置锁定、动画、本机管理 API 回归通过。
- 最终裁剪后的文件夹程序启动、跨隔离配置读取、更新启动窗口回归通过，配置逐字节不变；检查 asar 内容与最新源码一致。
- Windows 更新助手的 portable、ZIP、启动失败回滚、安装失败回滚、非法 ZIP 场景通过。
- 最终程序的真实 ZIP 下载、签名/哈希校验、替换、重启通过，并确认重启后存在可见原生窗口、配置逐字节不变。安装版/单 EXE 的最终 GUI 更新未在本轮重新完整实测，共用启动路径由窗口与更新助手专项覆盖。

## 保留项

Node 网关仍有构建入口与回归用途；Go 的独立服务、Redis、配额持久化、流式背压、安全校验仍有实际功能，不作为死代码删除。本轮属于有针对性的审查与清理，不宣称已证明整个项目不存在其他未使用代码或性能热点。已有未跟踪的消融实验脚本未删除或提交。
