# 请求 IP 显示与记录

设置 → 连接中的“显示请求IP”仅控制请求列表中的 IP 列。关闭时仍记录新请求的 IP；重新开启后，本次运行中尚未被淘汰的记录可以显示对应地址。

IP 随请求记录保存在有数量上限的内存缓冲中，清空记录或退出程序后删除，不写入配置文件或计费审计。HTTP 请求（包括未通过鉴权、被黑名单拒绝的请求）和 WebSocket 请求均记录地址。

显示关闭时桌面快照和增量消息不携带 IP，导出也不包含 IP；显示开启后恢复提供原始记录中的地址。黑名单在两种显示状态下均生效。该设置不下发到 Go 网关，不影响活动请求。

更新前未采集的地址无法补回；本次修复适用于使用修复版网关后收到的新请求。
